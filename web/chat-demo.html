Court chat

The panel from web/chat.js, on its own. Demo mode below makes no network calls at all; point it at a running kourtchat to use it for real.

Demo mode

A fixed sample thread. This is what a court page shows when chat is not configured, or when the overlay is in demo mode — an empty panel would misrepresent the feature, and calling out to a guessed origin would be worse.

Against a live service

Kept in localStorage so a reload keeps it. The service needs to allow this origin; it sends Access-Control-Allow-Origin: *, which is why opening this file straight off disk works.

Hostile input

Paste anything — a script tag, an onerror handler, a URL, a right-to-left override. It is rendered through the same chatLogHtml the panel uses, locally, and sent nowhere.

    The escaping is the only thing between a message body and script execution: the server preserves markup on purpose, so that what the classifier reads is what a reader sees. See the header of web/chat.js.
